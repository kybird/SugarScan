# 학습 예산이 다른 A/B 로 판정을 내리는 것

바꾼 변인(크롭·워프·증강)과 **함께 움직이지 않은 변인**(에폭 수·사전학습 체크포인트·
배치 크기)이 있으면, 나중 변인의 차이가 전부 변인의 효과로 기록된다. 학습량이
모자란 팔은 "그 변경이 나쁘다"가 아니라 "덜 학습됐다"로만 낮게 나온다.

## 실패 모드

G30 세로형 밴드 크롭 A/B: 새 팔은 스크립트 기본값(파인튜닝 12에폭)으로 돌고
기준선은 60에폭이었다. 결과 87.79%/위험 8.29% vs 기준선 97.06%/0.98% — "크롭이
크게 나쁘다"로 읽힐 뻔했다.

G31 이 같은 팔을 60에폭으로 재측정: **95.72%/3.48%**. 격차의 약 6/7 이 학습
예산 차이였다(최종 손실 0.9616 → 0.1095, 기준선 0.1238). 예산을 맞춰도 기각은
유지됐지만 **이유가 완전히 달라졌다** — "덜 학습돼서"가 아니라 "오답의 성격이
바뀌어서". 판정의 근거가 바뀌면 후속 조치도 바뀐다.

예산은 에폭만이 아니다: 같은 사전학습 체크포인트에서 시작하는지(장면 성분 재학습
실험은 pre_best 복사로 고정), 배치·조기중단·데이터 양도 예산이다. 재분할로 홀드아웃
비율이 45%→53% 로 바뀐 것도 조건으로 명시해야 비교의 성립 요건이 보인다.

## 점검 체크리스트

- [ ] A/B 양쪽의 **에폭 수·손실 종착점**을 나란히 적었는가 (손실이 아직 하강
      중이면 "더 학습하면 달라질" 여지를 결과에 명시)
- [ ] 시작점(사전학습 가중치)이 같은가 — 다르면 그것부터 변인이다
- [ ] 데이터 양·배치·증강 확률이 우연히 함께 바뀌지 않았는가
- [ ] "팔이 나쁘다" 결론 전에 **예산을 맞춘 재측정**을 한 번 했는가
- [ ] 분할·데이터셋이 바뀐 비교라면 조건 자체를 결과표에 적었는가

## 왜 이게 반복되는가

짧은 에폭은 빨리 끝나므로 먼저 보고되고, 낮은 숫자가 "변경이 나쁘다"는 그럴듯한
이야기와 만나면 굳은 신념이 된다. 예산 차이는 결과 표 어디에도 자동으로 찍히지
않는다 — **실험자가 적지 않으면 없는 것과 같다.**
