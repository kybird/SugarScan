# 분포가 넓은 모집단에 하나의 값·하나의 변환을 적용하는 것

측정해서 중앙값을 얻은 뒤 **그 값을 전체에 똑같이** 적용하는 것. 절반은 좋아지고 절반은 나빠져 합이 손실로 남는다.

## 실패 모드

한 세션에 **세 번** 같은 모양으로 일어났다.

| 처방 | 근거로 삼은 값 | 결과 |
|---|---|---|
| 추론 시 오른쪽 +8% 패딩 | 오른쪽 오차 중앙 +6% | 마지막 자리 오류 34→23 인데 전체는 **−0.62pp** |
| 일률적 여유 확대(사방 +8%) | 같은 값 | **−6.24pp** |
| CLAHE 전면 적용 | 저대비 장이 실패한다 | 분리도 0.759→0.744, **개선된 장 43%** |

세 번 다 "그 값이 필요한 장"에는 도움이 됐고 "이미 맞는 장"에는 배경·잡음만 더했다.

**신호는 분포 자체에 있었다.** 오른쪽 오차는 p5 −6% ~ p95 +28%, **표준편차 0.096 이 평균 0.072 보다 크다.** 이런 모집단에 스칼라 하나를 맞출 방법은 없다. 79% 는 덜 덮이고 11% 는 오히려 더 덮는데, 어떤 값을 골라도 한쪽이 손해다.

CLAHE 도 같다 — 국소 대비를 키우지만 **신호와 잡음을 구분하지 않아** 저대비 화면의 옅은 획과 함께 반사 자국까지 진해진다(`488`).

## 점검 체크리스트

- [ ] 중앙값·평균만 보고 처방하고 있지 않은가. **분산과 사분위를 봤는가**
- [ ] 표준편차가 평균과 비슷하거나 크면 **단일 값은 이미 실패**다
- [ ] 부호가 뒤집히는 장이 있는가(여기서는 11% 가 반대 방향이었다). 있으면
      "정도의 차이"가 아니라 **다른 모집단**이 섞여 있다
- [ ] 변마다·장마다 다른 값이 필요한 문제를 하나의 스칼라로 표현하고 있지 않은가
- [ ] 그 변환이 **신호와 잡음을 구분하는가.** 대비 강화·선명화는 대개 구분하지 않는다

## 무엇이 대신 통했나

**하나를 고르지 않는 쪽**이 통했다.

- 여유: 고정값 대신 **여유를 주고 학습 증강이 그 안에서 프레이밍을 흔들게** 했다.
  모델이 빡빡한 크롭과 헐거운 크롭을 모두 보게 되어, 위험군 3.83% → 1.60%.
- 판독: 단일 추론 대신 **여러 번 흔들어 읽고 다수결**. 94.83% → 96.88%.
- 여유의 비대칭: 스칼라를 **(왼,오른,위,아래) 네 값**으로 바꿨다. 오른쪽 오차가
  왼쪽의 3배인데 같은 값을 주고 있었다.

공통점은 **결정을 전처리에서 하지 않고 뒤로 미루거나 여러 경우를 함께 보는 것**이다.
