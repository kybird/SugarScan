# 무엇을 검증했는지 없이 "통과했다"만 적는 것

`눈검증: glucose_batch1/10 쿼드가 표시 이미지에서 유리 정확히 감쌈`

읽으면 "변환본을 검증했고 통과했다"로 읽힌다. 그런데 **어느 파일의 쿼드였는지가
적혀 있지 않다.**

## 실패 모드

2026-09-02: 위 기록을 근거로 `gmscreen_quads_oriented.jsonl`(변환본)이 검증된
것으로 취급했다. 나중에 재현해 보니 **원본** 쿼드가 유리를 감싸고 변환본은
어긋난다. 즉 당시 통과한 것은 원본이었을 가능성이 높은데, 기록만으로는
**복원이 불가능**하다.

그 결과 이중 회전된 힌트가 "검증됨" 딱지를 달고 살아남았고, 라벨링 재개 직전까지
아무도 의심하지 않았다.

## 점검 체크리스트

- [ ] 검증 기록에 **입력이 무엇이었는지**가 적혀 있는가 (파일명·경로·커밋)
- [ ] 비교 대상이 둘이면 **둘 다** 결과를 적었는가 ("A 는 맞고 B 는 틀렸다")
- [ ] 산출물(크롭 이미지 등)이 남아 있는가, 어디에
- [ ] 재현 명령이 적혀 있는가
- [ ] "통과"가 아니라 **관측한 것**을 적었는가 (유리를 감쌌다 / 오른쪽으로 밀렸다)

## 올바른 대안

```
검증: glucose_batch1/10 (ori=6)
  gmscreen_quads.jsonl 쿼드 → 표시 이미지에 그대로: 유리 정확히 감쌈  ✓
  같은 쿼드에 ori=6 회전 적용   → 오른쪽 밀림, 배터리 아이콘 잘림    ✗
  산출물: _diag/verdict_glucose_batch1__10_{a_asis,b_rotated}.png
```
