# "경계 안에 들어오면 맞다"고 판정하는 것

파손된 좌표를 보정할 때 **결과가 이미지 경계 안에 들어오는지**로 맞았는지 판정하는 것.

## 실패 모드

경계는 필요조건일 뿐 충분조건이 아니다. 2026-09-02 에 band 라벨 5건을 "스왑 프레임 + 비등비 스케일"로 보정했더니 **전부 경계 안에 들어왔다.** 하지만 실제 원인은 회전이었고, 그 보정을 적용했으면 좌표가 그럴듯하게 틀린 채로 학습에 들어갔을 것이다.

라벨 파손은 두 종류가 겹칠 수 있다(배율 밀림 / 회전). 한쪽 처방을 다른 쪽에 적용하면 경계 검사만 통과한다.

## 점검 체크리스트

- [ ] 보정 결과를 **크롭해서 눈으로** 봤는가
- [ ] 표본을 하나가 아니라 둘 이상 봤는가
- [ ] 파손 지문(예: 세로 점유율 ~0.52, 가로 1.0 초과)이 **일관되게** 설명되는가
- [ ] 원인이 다르면 스크립트를 나눴는가
- [ ] `--apply` 없이 먼저 돌려 봤는가
