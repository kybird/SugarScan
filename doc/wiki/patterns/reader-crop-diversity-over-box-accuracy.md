# 리더 학습 상자는 정확할수록 좋은 게 아니다 — **크롭 다양성**이 일반화를 만든다

판독 리더(2단 모델)의 학습 크롭을 검출기 예측 상자로 만들 때, **배포 검출기와
같을수록(정확할수록) 실사진 성적이 나빠질 수 있다.** 정확한 상자는 크롭이 항상
같은 자리를 자르게 해 리더를 과적합시키고, "어긋난 상자 + 흔들기"가 주는 다양한
크롭 위치·크기가 실제 배포 변동에 대한 일반화를 만든다.

## 사례 (2026-10-03, 전량 2,512장 끝단)

| 리더 학습 상자 | jitter | 끝단 |
|---|---|---|
| 옛 검출기 파일(우연히 어긋남) | 0.12 | **88.9%** |
| 같은 파일 | **0** | **3.8%** — 좌표 어긋남이 드러나 학습 붕괴 |
| 정확한 상자(현행 검출기) | 0.12 | 87.5~88.3% |
| 정확한 상자 | **0** | 79.5% — 학습셋 100% 암기(과적합) |
| 정확한 상자 + 균일 지터 확대(0.20) | 0.20 | 86.3% — 잘린 크롭만 늘어 역행 |

- 88.9%의 비결은 "정합"이 아니라 **우연한 어긋남 + 지터가 만든 크롭 다양성**이었다.
  지터를 빼자 같은 상자로 학습 자체가 실패(62%·3.8%)하며 어긋남이 증명됐다.
- 균일 랜덤 지터를 키워 다양성을 복구하려는 시도는 실패 — 숫자가 잘린 크롭이
  늘어 CTC 자릿수 포기를 가르친다. 필요한 건 **그럴듯한 상자 오차의 다양성**이다.
- 시프트·스케일 별도 축의 인위적 편차(perturb_boxes)도 86.3%로 우연을 못 이겼다 —
  오차의 '양'이 아니라 분포의 구조(상관·편향)가 자산인 것으로 보이나 재현 실패로
  탐색 종결.

## 글리프 축과의 곱

같은 시리즈에서 확립: **글리프 증강은 실촬 '종류' 관찰에서 온다** — 실촬 7에
완전형/축약형(A획 30~70%) 두 종류가 있다는 눈검 판정으로 A획 길이 축을 만들자
7→1 오독 26→5장, 끝단 88.3→**89.9%**(v8). 반대로 정확한 상자만으로 배우면
증강 이득(+10장)이 다양성 손실(−25장)에 묻혔다(v4).

## The Rule

- 리더 학습 상자 소스를 "배포와 같게" 정합하는 것은 **필요조건이 아니다** —
  크롭 다양성의 하한을 겨냥아라. 정확한 상자를 쓴다면 흔들기·증강으로 다양성을
  따로 사야 한다.
- 균일 랜덤 흔들기는 다양성이 아니라 **잘림**을 늘린다 — 스케일 하한·시프트 중심의
  '그럴듯한 오차'여야 한다.
- 우연히 좋은 성적의 학습 데이터(재현 불가 자산)보다 0.6pp 낮아도 **전 과정 재현
  가능한 프로세스**가 배포 자산이다(v2.1 88.9% → v8 89.9%로 역전되며 무의미해졌지만).
- 비교는 같은 모집단·같은 스크래치 조건에서 — 이 시리즈는 전부 스크래치 150에폭이라
  상자·지터·증강 축만 갈렸다.
