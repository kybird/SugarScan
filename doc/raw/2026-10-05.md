## Case 1: 줌 하한은 '유리' 기준 — 라벨 23%가 사람 GT 최소 밑에서 학습됐다

### Grounding
- Git Context: `hash:24a0e14`
- Evidence: assets_dev/train/_diag/audit_gen2p_axes.py 산출(합성 300판 중 69판<0.0367) · 사람 GT 350개 최소 0.0367 재측정 · synth_panel.py MIN_BAND_FRAC 주석
- Confidence: 5/5

### Error
2026-09-28 결정("실촬에 없는 스케일을 가르치지 않는다", 줌 하한 0.10→0.25)이
지켜진 것으로 여겨졌으나, GEN2P 300장 재니 **라벨의 23%가 사람 GT 최소
면적비(3.67%) 밑, 9%가 2% 밑, 최소 0.66%**. 줌 하한은 '유리가 프레임을
채우는 배율' 기준이라 밴드 비중은 프로파일이 좁은 장에서 더 내려간다.

### Environment Context
- Packages: sugartrain(cv2·numpy)
- Migration Issue: No

### Fix Code
```python
MIN_BAND_FRAC = 0.0367   # 사람 GT 350개 최소 면적비
_bq = _warp_pts(quad0, Mk, Mr) if Mk is not None else quad0
_brel = _area([np.asarray(_p, np.float64) for _p in _bq]) / (W * H)
if _brel < MIN_BAND_FRAC:      # 중심 확대로 끌어올림(유리 접촉 배율 상한)
    ...Mk = Mz @ Mk
```
잔여 누수 122판(유리가 이미 프레임에 닿아 확대 여유 없음)은 COCO에서
**이미지째** 제외(_diag/patch_gen2_minfrac.py) — 라벨만 빼면 '보이는
밴드=배경' 거짓 음성을 가르친다.

### Analysis
- Root cause: 스케일 금지 규칙이 '배율'이라는 대리변수에 걸려 있었다.
  규칙의 본체(라벨 면적비)를 직접 게이트해야 한다.
- Why it failed: 유리 기준 하한이 밴드 기준 하한으로 읽힘 — 대리변수와
  규약의 혼동.
- How it was fixed: 문턱을 라벨 면적비로 옮기고, 렌더 게이트(확대로
  끌어올림)+굽기 후 필터(제외) 2단 방어.
- **2차 실수**: 첫 구현이 `visible_frac`(프레임 안에 들어가는 비율 — 사다리
  경로에서 늘 1.0)을 문턱으로 써서 같은 시드에 같은 숫자가 나오는 것으로
  미적용이 발각. **면적비는 _area/(W·H), 가시비는 visible_frac — 이름이
  아니라 정의를 확인하라.** '같은 시드·같은 숫자'는 변경 미적용의 신호다.

## Case 7: '큰 글자=밴드' 지름긋값을 경쟁 인쇄로 끊는다 — 사람 원칙 실증

### Grounding
- Git Context: `hash:24a0e14`
- Artifact: synth_panel.py comp_print·GEN2P 감사(경쟁인쇄 3.6%·숫자급 픽토그램 1.5%)·e2e 회복 목록
- Confidence: 5/5

### Design Decision
검출기의 닻은 혈통·기기 외모가 아니라 **큰 숫자 글리프 자체**다(사람
선언). gen1 잔여 실패 11장 중 5장이 '숫자 아닌 큰 인쇄물에 상자가 훔쳐진'
것(세리프 GREEN 로고·문서 픽토그램 — 숫자는 또렷했다)이었다. 숫자급
크기의 비숫자 글리프를 밴드 이웃에 두고 라벨은 숫자줄만 유지하는 네거티브
축(comp_print·큰 픽토그램·잘림·직격반사)을 넣었다.

### Alternatives Considered
- 혈통(기종 프로파일) 추가 — 사람 기각("기종추가안하고 다른것들만하자").
- 프레이밍(클로즈업) 축 — 실측 기각: 합성 밴드 비중 최대 0.412 로 이미
  커버, 실패 장들은 정상 구도였다.
- Selected: 외관 공간 축(고정 기기는 레이아웃 고정 원칙 유지, generic_v1
  만 형질 추출 — 비중 3.85→10%).

### Decision Code
GEN2 코퍼스 29,878장: 경쟁인쇄 3.6%·숫자급 픽토그램 1.5%·잘림 2.1%·
반사 4.9%·그림자 17.3%(동일 예산 학습).

### Analysis
- Context: 검출 실패 16장 중 5장이 상자 훔침 — 모델이 '가장 큰 글자'를
  닻으로 쓴다는 증거.
- **Trade-offs**: 기기 충실성(고정 기기에 랜덤 인쇄 금지) vs 일반화 압력
  (generic 품에서만 다양성) — 분리로 둘 다 유지.
- Reversibility: High (코퍼스 상수).
- 결과: 상자 훔침 4장·1780·818 전량 회복, 검출 실패 16→1(2317).
