## Goal
<!-- kanban:goal:begin -->
이탤릭 글리프 기기에서 단위를 빼고 숫자 필드만 감쌀 수 있도록 밴드 박스에 기울기를 더한다. 자유 4점이 아니라 제약된 핸들로 — 사람 손으로 평행사변형을 정확히 찍을 수 없기 때문이다.
<!-- kanban:goal:end -->

## Acceptance Criteria
<!-- kanban:ac:begin -->
- [ ] #1 박스가 직사각형 + 기울임(shear) + 회전(rotation) 여섯 자유도로 조절된다. 네 꼭짓점을 따로 움직이는 방식이 아니다 — 마주 보는 변은 항상 평행하고 길이가 같다
- [ ] #2 기울임과 회전은 각각 전용 핸들 하나로 조절되고, 키보드로 0.5도 단위 미세 조정이 된다
- [ ] #3 기울임 0, 회전 0 이면 현재 축 정렬 박스와 완전히 같다. 기존 라벨을 열고 아무것도 건드리지 않고 저장하면 좌표가 한 자리도 변하지 않는다
- [ ] #4 같은 기기의 직전 라벨에서 기울임·회전 값을 기본값으로 물려받는다 — 기울기는 사진의 성질이 아니라 기기의 성질이다
- [ ] #5 기운 쿼드를 저장한 뒤 다시 열면 기울기가 그대로 복원된다 — quadToAABB 로 납작해지지 않는다
- [ ] #6 digit_top(숫자 윗변 방향)이 함께 저장된다
