## Goal
<!-- kanban:goal:begin -->
검출기의 입력은 GM 크롭이고 거기엔 기기 몸체가 들어 있다(몸체 인쇄 브랜드·모델명, 몸체 윤곽 곡선, 움푹한 베젤, 그림자). 합성은 패널만 그린다. 학습 입력과 추론 입력이 다른 물건이다. 밀도 격차도 전량 여기서 온다 — diag_density_where.py ring 으로 재면 실사진은 바깥 링(15%) 2.84% / 안쪽 1.38%, 합성은 바깥 링 1.77% / 안쪽 1.50% 다. 합성의 안쪽은 이미 실사진보다 높다. 부족한 것은 몸체다.
<!-- kanban:goal:end -->

## Acceptance Criteria
<!-- kanban:ac:begin -->
- [x] #1 합성 이미지가 GM 크롭과 같은 물건이 된다 — 패널 둘레에 기기 몸체가 그려진다. 폭을 넓힐지 기존 margin 을 채울지는 실측으로 정하고 근거를 적는다
- [x] #2 밴드 쿼드 좌표가 새 캔버스 기준으로 정확하다 — glyph_plane_check 자가검사가 유지되고 montage 오버레이가 숫자줄에 정확히 붙는다
- [x] #3 바깥 링(15%) 엣지 밀도가 실사진 2.84% 의 ±0.5pp 안에 든다. diag_density_where.py ring 으로 재고 n 을 적는다
- [x] #4 안쪽 밀도를 올리지 않는다 — 현재 1.50%, 실사진 1.38%. 1.70% 를 넘기면 실패다. LCD 안에 요소를 더 넣어 수치를 맞추지 마라
- [x] #5 전체 밴드 밖 밀도가 실사진 2.52% 의 ±0.5pp 안에 든다(measure_panel_stats synth-density, frame-exc 0, n=300)
- [x] #6 몸체 요소마다 근거 사진 id 를 단다 — 몸체 인쇄 브랜드·모델명(Gmate 713·722, CareTouch/MM1000 92·97·100, Boryung 97), 몸체 윤곽 곡선, 움푹한 베젤, 그림자. 근거 없는 요소를 지어내지 마라
- [x] #7 종횡비와 밴드 기하가 깨지지 않는다 — measure_panel_stats synth-band 로 재확인. 세로형 band_w 0.827 / band_h 0.458 / cy 0.391, 종횡비 median 0.792 가 실사진 기준이다
- [x] #8 12장 montage 눈검 — 몸체가 실기기처럼 보이고, 같은 라벨 부류 중복 없고, 도트줄 2줄 이하
