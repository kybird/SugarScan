## Goal
<!-- kanban:goal:begin -->
기기마다 다른 화면 배치를 프로파일로 정의하고 합성이 그중 하나를 골라 렌더하게 만든다. 실패 원인 1위인 '숫자 옆 글리프'(화살표·단위·아이콘·도트매트릭스)를 합성이 실제로 담게 하는 것이 목적이다.
<!-- kanban:goal:end -->

## Acceptance Criteria
<!-- kanban:ac:begin -->
- [x] #1 기기 프로파일이 데이터로 정의된다 — 숫자 정렬·단위 위치와 표기 방식·아이콘 종류와 위치·보조 줄(시간/도트매트릭스) 유무
- [x] #2 실사진에서 관찰된 프로파일이 최소 6종 정의되고, 각 프로파일이 어느 실기기에서 왔는지 근거 id 가 적힌다
- [x] #3 아이콘·화살표는 라벨에 포함되지 않는다 — 모델이 그 자리에 blank 를 내도록 배워야 한다는 것이 이 카드의 요점이다
- [x] #4 생성기 품질 지표(합성만 학습 -> 실사진 평가)로 개선 전후를 비교한 수치가 보고된다
- [x] #5 방해 글리프가 실제로 렌더된다 — 최소한 오른쪽/왼쪽 화살표, 배터리, 혈액방울, 식전·식후 마커, 도트매트릭스 보조줄. 숫자에 바짝 붙는 배치를 포함한다(붙지 않으면 실패를 재현하지 못한다)
- [x] #6 베젤에 인쇄된 문자열과 물리 버튼이 프레임 가장자리에 렌더된다 — 워프 박스가 LCD 보다 넓게 잡혀 실제로 프레임 안에 들어온다
