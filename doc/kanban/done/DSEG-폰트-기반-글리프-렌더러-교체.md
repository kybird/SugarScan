## Notes
- 2026-09-11T18:28-07:00 — 폰트: DSEG (keshikan). github.com/keshikan/DSEG · www.keshikan.net/fonts-e.html. Ver0.40 부터 SIL Open Font License 1.1 — 상업 이용·수정·재배포 허용. 우리는 학습 이미지를 렌더하는 데만 쓰고 앱에는 넣지 않는다. 폰트 파일을 저장소에 들이면 OFL 원문을 함께 두고 docs/LICENSES.md 에 등재할 것 — 라이선스 등재가 이 카드의 첫 AC 인 이유다(EasyOCR 가중치가 지금도 미확인으로 남아 있다).
- 2026-09-11T18:28-07:00 — OFL 의 Reserved Font Name 조항: 폰트를 수정해 재배포하면 이름을 바꿔야 한다. 우리는 수정 없이 렌더에만 쓰므로 해당 없지만, 굵기를 코드로 늘리는 식의 변형을 폰트 파일에 가하지 말 것 — 변형이 필요하면 렌더 단계에서 한다.
- 2026-09-11T18:28-07:00 — DSEG 에는 7세그·14세그와 여러 변형(Classic/Modern, 이탤릭, Light~Bold)이 있다. 실사진의 글리프 인상에 가장 가까운 변형을 눈으로 골라 보고서에 근거와 함께 적을 것 — 아무거나 첫 번째를 쓰지 말 것.
- 2026-09-11T18:28-07:00 — 꺼진 세그먼트 잔상이 중요하다. 실제 7세그 LCD 는 꺼진 획도 배경보다 옅게 보이고, 그래서 실사진의 8 과 0 은 '보이는 획'이 아니라 '진한 획'으로 구분된다. DSEG 는 모든 세그먼트가 켜진 문자를 제공하므로 그것을 옅게 겹쳐 그리면 된다. 농도는 고정값이 아니라 표본마다 흔들 것.
- 2026-09-11T18:28-07:00 — 건드리지 말 것: 배치 계산(우정렬·셀 폭·y0)과 라벨 생성 경로. 라벨 문자열은 숫자만 담는다.
- 2026-09-11T20:18-07:00 — 정정(2026-09-11 실사진 확인): 꺼진 세그먼트 잔상은 생각보다 훨씬 약하다. 2자리 값 사진 세 장(GC 녹십자 MS ONE 55 · SD CodeFree 84 · Gmate 98)에서 빈 앞칸에 아무 흔적이 없다 — 패널이 균일하다. 따라서 잔상을 항상 켜지 말 것. 프로파일 속성으로 두고 '없음'을 포함한 넓은 범위로 흔들어라. 잔상을 기본값으로 강하게 넣으면 실사진에 없는 단서를 가르친다.
