# 웹툴 화면 지도

서버는 `webtool.py`(포트 8777, 표준 라이브러리만). 스크립트 지도는
`SCRIPTS.md`, **이 문서는 화면 지도**다. 2026-09-21 사람 우려("계속해서
페이지가 추가되는데 우려스럽다")로 세웠다 — 우려는 사실이었다: 페이지 10개
중 5개가 직전 4일(09-18~21)에 늘었다.

**규칙 — 새 화면을 만들기 전에 이 표에 먼저 한 줄을 적는다.**

- 기존 화면으로 커버되면 **화면을 늘리지 않고 그 화면에 모드를 넣는다.**
- 화면은 결론을 만드는 도구라(틀 자체가 증거다 — Case 9), 늘어난 채로
  방치되면 "어느 화면이 정본인가"부터 헷갈린다. 서버 머리말의 API 목록이
  낡아서 갱신 안 된 것이 이미 그 사고의 전조였다.
- 화면이 읽는 데이터 원천(배치 파일인가 라이브 추론인가 사람 입력인가)을
  표에 적는다 — 배치 산물은 **낡을 수 있고 낡은 걸 화면이 숨긴다**(2026-09-21
  오버레이가 두 팔 뒤진 `bg_s1` 인 걸 아무도 몰랐다).

## 작업대(`/`)의 다섯 탭

- **라벨러** — 밴드·LCD 라벨 캔버스. 쓰는 것: `band_boxes.jsonl` ·
  `screen_boxes.jsonl`(사람 라벨 정본), `band_quads_pred.jsonl`(예측 오버레이,
  **배치 힌트** — 2026-09-21 현재 `asize512_s0`).
- **모니터** — 학습 로그. `band_out/` 의 가장 최근 로그를 따라간다.
- **기종** — 사진 위 예측 오버레이 + 검출기 갈아끼우기. 오버레이는
  `band_quads_pred.jsonl`(배치).
- **아틀라스** — 8790 포트의 `atlas_synth_vs_real.py` 서버를 프록시.
- **훈련** — 검출기 학습 시작·중지·게이트. 옛 계열(`band_det_*`) 버튼이
  남아 있다 — 아래 "정리 후보".

## 화면을 떠받치는 비(非)화면 라우트

- `/api/image?id=&w=` — JSON 으로 캐시 URL. `/photo` — `<img src>` 직접
  쓰는 이진 응답. **둘이 갈라진 이유가 있다**(G34: JSON 을 img 태그에
  물리면 깨진다). 리사이즈 규약은 공유 — 갈라지면 안 된다.
- `/synthimg` — 합성 PNG 원본(좌표가 manifest 화소 기준이라 리사이즈 금지).
- `/atlas`·`/imgs/`·`/api/cases`·`/api/review` — 8790 아틀라스 프록시.
- `/api/livecmp` · `/api/arms` · `/api/inkclip` · `/api/aug` ·
  `/api/bandreal` · `/api/rfqueue` — 각 화면의 데이터.

## 겹침과 정리 후보 (2026-09-21 평가 — 사람 판정 대기)

1. **`/arms` 와 `/livecmp`** — 같은 질문(두 팔 눈비교)을 다른 방식.
   `/arms` = 배치 집약(4시드 합산, "게이트가 갈린 장" 필터 탐색),
   `/livecmp` = 라이브 단장·목록(시드 개별, 즉석). 당장 병립 근거는 있으나
   **새 비교 화면은 만들지 않는다 — `/livecmp`를 늘린다.** 배치 의존은
   산물이 낡으면 화면도 낡는다는 위험이 이미 현실이 됐다.
2. **`/rfband`** — 임무 소멸. 규약 차이가 잉크 자로 확정돼 79장 라벨링이
   불필요해졌다(BAND_EXP_PLAN §23.5). 라벨 파일·큐는 보존, 화면은 폐기
   후보.
3. **훈련 탭·기종 탭의 `band_det_*` 갈아끼우기** — 전부 폐기된 옛 계열
   이름만 목록에 뜬다. 새 체크포인트 검사는 `/livecmp`로 한다. 버튼·
   드롭다운 정리 후보.
4. ~~**`/bandreal`** — `/livecmp`와 부분 겹침, 장기 흡수 후보~~ →
   **2026-09-21 흡수 완료**(위 표 각주).
5. **`webtool.py` 머리말의 API 목록** — ctc 폐기 파이프라인(`ctc_train_gpu.log`
   등)이 남아 있어 이미 낡았다. **화면·API 의 정본은 이 문서**다(머리말은
   실행법만 남겼다).
