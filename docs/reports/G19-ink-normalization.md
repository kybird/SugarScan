# G19 — 셀 정규화를 플래그 뒤에 구현하고 A/B 측정

- 브랜치: `glm/G19-ink-normalization`
- 커밋: 이 보고서와 함께 하나
- 상태: 완료 — **채택 여부는 이 문서가 정하지 않는다.** 기본값은 꺼져 있다.

## 무엇을 했나

- `lib/ocr/src/engines/segment_rule/segment_sampler.dart` — `sample()` 에
  `bool normalizeToInk = false` 추가. 셀 안 전경(잉크)의 경계 상자를 구해
  **높이 ≥ 셀 높이의 40% · 폭 ≤ 셀 폭의 95%** 일 때만 세그먼트 기하의 기준을
  셀에서 잉크 상자로 옮긴다(잉크 상자 둘레에 2% 여유). 전경이 없거나 두
  걸러냄에 걸리면 기존 경로 그대로다.
- `segment_rule_engine.dart` — 생성자에 `this.normalizeToInk = false` 추가해
  샘플러로 흘린다. **부트스트랩(`ocr_bootstrap.dart`)은 무수지** — 기본값 끔.
- `cell_bench.dart` · `scene_bench.dart` — `--normalize-ink` 플래그. 장면 벤치
  리포트 머리에 어느 팔인지(켬/끔) 기록해 재현 근거를 남긴다.
- `test/ocr/segment_sampler_ink_test.dart` — 유닛 테스트 3건(아래).

## 왜 그렇게 했나

- 지시서의 숫자(40% · 95% · 2%)를 그대로 썼다. 2% 여유는 "경계 상자 둘레에"
  라는 문구를 **변별(폭/높이)당 2%, 즉 상자를 1.04배로 확장**으로 읽었다.
- 걸러냄 판정은 실제 전경 픽셀로 측정한 경계 상자 기준이다(획 그리기의
  반올림 여유까지 포함된, 엔진이 실제로 보는 상자).
- 장면 벤치는 엔진 전체 경로를 돌므로 플래그를 엔진 생성자로 흘렸다 —
  벤치가 샘플러를 직접 부르면 측정 경로가 앱과 갈라진다.

## A/B 측정

전량, 임계치·기하 무수정, 플래그만 갈랐다.

### 셀 벤치(41,990장 · 01.dataset)

| | 끔 | 켬 |
|---|---|---|
| 완전일치 | 11,304 (26.92%) | 13,620 (32.44%) |
| **치명적 오독** | **3,658 (8.71%)** | **4,249 (10.12%)** |
| 미판독 | 27,028 (64.37%) | 24,121 (57.44%) |
| `0`→`H` | 683 | **204** |
| `8`→`H` | 555 | 457 |

### 장면 벤치(2,000장 · assets_dev/synth)

| | 끔 | 켬 |
|---|---|---|
| 완전일치 | 3 (0.15%) | 27 (1.35%) |
| **치명적 오독** | **120 (6.00%)** | **166 (8.30%)** |
| 미인식 | 1,877 (93.85%) | 1,807 (90.35%) |

(`0`→`H`·`8`→`H` 행은 셀 벤치의 혼동표 지표다 — 장면 벤치에는 대응 표가 없다.)

### 읽는 법 — 사실만

- **두 벤치에서 같은 방향이다.** 미판독이 값으로 바뀌며 정답과 오독이 함께
  늘고, 오독 증가분이 상대적으로 크다(셀 +591 건 · 장면 +46 건 = +16%／+38%).
- 셀 벤치에서 정규화가 새로 값으로 바꾼 2,907건 중 2,316건이 정답,
  **591건(20.3%)이 틀린 값**이다. 이 앱에서 위험한 것은 틀린 값을 내는 것이다.
- **`0`→`H` 는 683→204(−70%)** — G15 가 지목한 통증 자체는 크게 줄어든다.
  `8`→`H` 도 555→457.
- **부수 악화 — 표시 없음(`11`) 클래스에서 값을 만들어내는 비율이
  86/1,992 (4.32%) → 110/1,992 (5.52%)** 로 올랐다(신규 `6` 27건 등). 꺼진
  화면에서 숫자를 지어내는 것은 이 벤치 기준으로 가장 나쁜 결과다.

## 유닛 테스트

`test/ocr/segment_sampler_ink_test.dart` — 셀 100×100 에 숫자 잉크를 지정
상자에만 그리는 픽스처:

1. **정규화 됨** — 잉크 높이 45%·폭 60%: 끔 팔은 8 이 아니게 읽고(위·아래
   가로 획을 여백에서 재는 G15 재현), 켬 팔은 `8`.
2. **40% 미만** — 잉크 높이 30%: 켬 팔의 bits 가 끔 팔과 동일(기존 경로로
   떨어짐).
3. **95% 초과** — 셀 전체 폭에 걸친 이웃 자릿수 모형: 동일하게 기존 경로.
