# 로보플로우 완전 미검출 — 구도/열화/이물 3분할 (2026-09-21)

카드: "로보플로우 완전 미검출을 구도·열화·이물로 3분할한다"
(마일스톤 "사진용 밴드 검출기의 장면 불일치를 검증한다")

## 정의 — 무엇을 '완전 미검출'로 세았는가

- **완전 미검출** = 검출기가 상자를 하나도 내지 못한 장. `report_fail_mix.py`의
  '미검출' 클래스 정의(`det` 없음)를 그대로 쓴다 — 새 분류 틀을 만들지 않았다.
- 검출기: `_diag/audit/roboflow_aug_{s5,s6,s7}.jsonl` 세 스냅샷. **한 팔이라도**
  미검출인 장(합집합)을 대상으로 했다. 세 팔 **교집합은 0장**이다 — 미검출 장이
  시드마다 완전히 바뀌므로 "전 팔 공통으로 죽는 장"은 존재하지 않고, 미검출은
  신호 경계의 우연이 지배한다. 합집합이 "이 코퍼스에서 가장 죽기 쉬운 장"의
  전수다.
- 모집단: **dev 586장만**(팔별 dev 미검출: s5 0장 · s6 4장 · s7 8장).
  봉인 시험(rf_split.json test 687)은 조건 선택에 쓰지 않는다(봉인 규약).
  측정 대상 **n = 12장**(dev의 2.0%).

## 자(尺) — 재현 명령

새 자 `assets_dev/train/classify_rf_miss.py`(이 커밋에 포함). 기존 자 재사용:
'미검출' 클래스 정의는 `report_fail_mix.py`(배포 상자·숫자 칸 관계 분류 틀),
세 축 신호의 블러 자(라플라시안 분산)는 `measure_panel_stats.py` 밀도 축의
측정 방식(사진에서 직접 잰다)을 따랐다.

```
cd assets_dev/train && conda run -n sugartrain python classify_rf_miss.py
# 산출: 콘솔 표 + _diag/rf_miss_split.json (전 장 신호·백분위·경로)
```

배정 규칙(사전 정의, dev 586 분포 기준 백분위): 이물후보(최빈색비율 ≥ p95
또는 고유색수 ≤ p5) > 열화(READING 라플라시안 ≤ p5 또는 바이트율 ≤ p5) >
구도(READING 상대면적 ≤ p5 또는 중심거리 ≥ p95). 이물 우선은 이물이 다른
신호까지 왜곡하기 때문. **이물 확정은 사람이 한다** — 형제 카드(이물층 태그
규약)의 "무인 루프가 태그 값을 만들지 않는다" 규약에 따라 이 자는 후보만
띄운다.

## 관찰 — '불명' 8장의 안쪽 (측정 후 발견, 규칙과 분리해 읽을 것)

- **6장이 같은 세션이다**: `IMG_6283`~`IMG_6288`(연속 촬영). 전부
  READING 상대면적 **p7~p10**(숫자 영역이 작다 = 기기가 조연) + READING
  라플라시안 **p93~p99**(매우 선명). 즉 "작고 선명한 조연 구도" 세션이
  미검출 과반(12장 중 6장, 50%)을 차지한다. 사전 규칙의 구도 문턱(p5)에
  걸리지 않은 것은 이 세션이 정확히 5% 선 위(p7~p10)에 있기 때문이다.
  세션 단위 몰림은 [[image-level-split-on-session-corpus]]의 재현 —
  같은 구도·조명의 연쇄 촬영이 한 코호트를 이룬다.
- 나머지 불명 2장(`IMG20241209125534`·`...538_01`)은 라플라시안 p8 /
  바이트율 p11 등 **열화 경계**에 있다(문턱 p5에 못 미침).
- 이물후보 1장(`IMG20241209123936`)은 고유색 수 55(= p5 경계)·최빈색
  p88 — 약한 신호다. 스크린샷·광고 여부는 사람 눈으로 확인해야 한다.

종합하면 사람 확인 전 단계의 배분 후보는 **구도 계열 6~7장 · 열화 계열
2~4장 · 이물 후보 1장**이고, 규칙 문턱을 적용한 확정 배분은 위 표다.

## 예산 근거로 읽는 법 (B3 열화 · B4 구도 카드로)

1. **완전 미검출은 희귀하다** — dev 2.0%이고 세 팔 교집합이 0장이라 상당수가
   시드 경계다. 지배적 실패는 09-20 표(`report_fail_mix`, aug_s0)의
   **잘림 7.0%** 쪽에 있다. 열화·구도 축의 기대 수익은 "미검출 방지"보다
   "잘림 완화·상자 품질"에서 계산하는 것이 맞다.
2. **구도 축(B4)의 근거는 세션이다** — 조연 구도 세션 1개(IMG_628x)가
   미검출 과반을 설명한다. 합성기 구도 축은 "기기 상대 크기 하위 분위"를
   재현하는 방향이고, 검증은 세션 단위 분할로 해야 같은 세션이 train/시험에
   흩어져 기록을 부풀리지 않는다([[scene-component-split]]).
3. **열화 축(B3)의 근거는 2~4장** — 흐림(라플라시안 p5) 1장, 강압축
   (바이트율 p1, WhatsApp 전송본) 1장이 명확하고 경계 2장이 뒤따른다.
   압축 열화는 배포 경로(메신저 전송)에서 온다.
