## 1. 현재 최적 스택

**GEN10B 가중치 + 640 추론** — 순수 합성(실사진 학습 0장), 생성기 무수술.

| | 정닥 확정 | 오답 확정 | 함정 확정 |

| 제품 번들 (실촉 2,504장 파인튜닝) | 138/198 (69.7%) | 13 (6.6%) | 12/30 (40.0%) |
| **GEN10B@640 (승자)** | **116/207 (56.0%)** | **4 (1.9%)** | **9/31 (29.0%)** |
| GEN9 (어제까지의 승자) | 96 (46.4%) | 9 (4.3%) | 9/31 |

- 구성: 12,000장 굽기(줌 하한 0.40·GEN5 광학축) → 검출기 416·batch128·
  2,250스텝·neg25 → 리더 100에폭 → **재판을 640 레터박스로**.
- 제품과의 간극 23pp → **13.7pp**. 오답은 제품(6.6%)의 1/3.
- 체크포인트: `band_out/ps10b_det_neg25.pt` · `reader_out/ps10b_rdr/best.pt`.
  배포 ONNX 재내보내기 전 상태(640 추론 정책 포함 확정 후).

## 4. 사람 결정 대기 (우선순위순)

1. **유리 영역 소형 분류기** — 방향(0/90/180/270) + 코드화면 동시 판별.
   산업 선례 PaddleOCR cls. 함정 9~19건·rot90 5건 회수가 몫. 착수 승인 필요.
2. **예산 곡선 추적** — 16k·24k 단일 축(굽기 1회씩). 정닥 상승이 어디서
   포화되는지. 자동 진행 가능(밤 체인 3~4개).
3. **배포 갱신 여부** — GEN10B@640을 ONNX 재내보내+앱 번들 교체+실기기
   검증할지. 함정 29%가 사람 확인층으로 커버되는 선인지 판단 포함.
4. **앱 MIN_FRAC 2%→1.5%** — 근거 1장(1.99%에서 완벽 판독).
5. **고해상도 합성 렌더** — 640 네이티브 학습의 전제였으나 **그 전제 논거는
   감사로 소멸**(업스케일 0건 — `gen10d-input-audit-2026-11-19.md`).
   렌더 축 자체는 다른 근거(실츬 해상도 다양성)로만 살릴 수 있음.
6. **종횡비 프로파일 수술** — 측정 완료(합성 +0.15~0.3 넓음), 우선순위 낮음.

## 5. 인프라·방법론 변화

- **리더 RAM 패딩 크롭 캐시**: 에폭 17.7초→2.8초(6.3배), 체인 49분→21분
  (55f58d9). 워커는 줄이는 게 정답(스폰 피클 비용).
- **채점기 집계 수정**(49e92c5): "확정"=앱 실제 확정만. 확신도차단 별도
  버킷 + 판독문자열 기록.
- **재현성 규칙**: worst 0.80~0.90 경계(59개)가 GPU 비결정성에 흔들림 —
  임계값 근처 재판은 기준 컬럼(416)이 재판 기준과 일치하는 실행만 채택.
- 통계 주의: n=207에서 오답 4건의 95%CI [0.7, 5.3] — "≤5% 달성"은
  관측이지 확정 아님(더 큰 판정 세트 필요).
