# 장면 성분 분할 재학습 — 세션 무결 새 기준선 96.67% / 위험 1.51%

2026-09-10 · 칸반 카드 「장면 성분 분할 재학습」.
전제: [`split-leakage-audit-2026-09-09.md`](split-leakage-audit-2026-09-09.md) —
기존 97.06%/0.98% 는 홀드아웃 73.7% 가 train 과 같은 장면을 공유한 누수 수치였다.

## 방법

1. **재분할**: `build_grouped_split.py` — dhash(해밍 ≤8) 연결요소 = 장면 세션을
   분할 단위로 real_train/real_holdout 을 재배열(워프 배열 재계산 아님).
   합성 배열은 기존 캐시에서 그대로 복사.
   - 임계 민감도: ≤6 → 성분 1,137개(최대 511장) / ≤8 → 710개(최대 723장).
     두 임계 모두 같은 구조(거대 단일 세션 성분)라 ≤8 을 유지했다(경계쌍
     눈검증 완료).
   - 분할: train 1,172 / holdout 1,322(53.0% — 마지막 성분이 커서 목표 45% 를
     넘게 쌓임). **교차 성분 0 검증 통과**.
   - 균형: 값 범위 train 30~511(평균 131) / holdout 51~465(평균 136), 2자리
     표본 256/256 — 한쪽으로 몰리지 않음.
2. **재학습**: `ctc_reader_v2.py ft 60 --data-root ../train_grouped` — 기준선과
   같은 사전학습 체크포인트(`pre_best.weights.h5` 복사)에서 같은 60에폭 예산.
   파인튜닝 데이터만 분할이 다르다 → 분할 효과가 분리된 비교.
   최종 ft 손실 0.218(기준선 0.124 — ft 데이터가 200장 적고 중복이 제거돼
   직접 비교 불가).
3. **평가**: `eval_reader.py` TTA(crc32 시드) — 기준선 97.06% 측정과 동일 프로토콜.

## 결과 — 새 기준선(교체 대상)

| 지표 | 옛 기준선(누수 분할) | **새 기준선(세션 무결)** |
|---|---|---|
| 완전일치 | 97.06% | **96.67%** (1,278/1,322) |
| 위험(자릿수 보존 오독) | 0.98% | **1.51%** (20건) |
| safe(자릿수 변동) | 1.69%* | 1.66% (22건) |
| blank | 0.27%* | 0.15% (2건) |
| 득표율 거절(agree<0.778) | 5.2%* | 6.4% (85건) |

*옛 분할 전체 1,122장 기준 재계산(감사 보고서와 동일 원천).

참고: 옛 모델을 누수 없는 층에서 재집계하면 94.24%/1.69% 였다 — 새 모델은
같은 "정직한 조건"에서 약 2.4pp 위다. 해석은 신중히: 두 층의 표본 구성이 다르고,
그룹 분할 훈련이 중복 장면을 제거해 에폭당 다양성이 올라간 효과일 수 있다.

## 해석과 규약

- **97.06%/0.98% 는 폐기한다.** 이후 모든 A/B 는 `train_grouped` 기준선
  (96.67%/1.51%) 위에서 비교한다. G29~G32 의 델타(짝비교)는 내부 정합성이
  있지만 절대 수치 인용은 이 보고서가 대체한다.
- 위험률 1.51%·득표율 거절 6.4% 가 이 코퍼스에서 정직한 실패 예산이다.
  거절 임계(0.778) 재스윕은 새 기준선 위에서 다시 해야 한다(구 G24 곡선은
  누수 분할 기준).
- 산출물: `assets_dev/train_grouped/`(캐시·reader_model·reader_preds_tta.json,
  전부 gitignored — `build_grouped_split.py` 로 재생성 가능).

## 한계

- 세션 정의는 dhash ≤8 에 의존 — 회전 근접쌍은 못 잡아 잔여 누수가 이론상
  가능하다(과소 추정 방향).
- holdout 이 53% 로 커졌다(거대 성분 하나가 목표 초과분). 평가는 더 강해졌고
  학습 데이터는 200장 줄었다 — 기준선 비교에는 양쪽 다 명시된 조건이다.
