# 기기 형질과 촬영 변인을 가른다

사람 지침(2026-09-13): **「디바이스에 고정 요소들을 확실하게 정하자. 랜덤요소와
고정요소로 나눠서 같은 기기는 일관성을 유지할 수 있게.」**

## 문제

실측이 있는 축(유리 종횡비·밴드 기하·세그먼트 굵기)만 `LAYOUTS` 로 고정돼
있었다. 실측이 없는 축은 전부 렌더 rng 에서 뽑혔다 — 몸체색, 모서리 반경,
베젤 홈, 칸 비율, 표기 포맷, 잔상, 액정 바탕/잉크 톤, 베젤 인쇄 문자열과 자리.
그래서 **같은 프로파일이 장마다 다른 물건으로 보였다.**

고정값을 새로 '정하는' 것은 답이 아니다 — 실측이 없으니 정할 근거가 없다.
대신 **뽑는 시점을 렌더에서 기기로 옮긴다.** 기기 id 로 씨를 만들어 형질을
한 번 뽑고 캐시한다(`synth_profiles.device_identity`). `zlib.crc32` 라
프로세스·시드·렌더 순서와 무관하게 같은 기기는 같은 형질을 받는다.

## 세 갈래

### A. 기기 형질 — 같은 기기면 항상 같다

| 축 | 출처 | 전 |
|---|---|---|
| 유리 종횡비 · 밴드 w/h/cx/cy | `LAYOUTS` 실측 중앙값 | 이미 고정 |
| 세그먼트 굵기 · 이탤릭 · 폰트 | `LAYOUTS` | 이미 고정 |
| 슬롯 수 · 정렬 · 도트패널 여부 | `PROFILES` | 이미 고정 |
| 단위 문자열(mg/dL vs mg /dL) | `crc32(pid)` | 이미 고정 |
| **몸체 플라스틱 톤** | `device_identity.body_u` | 렌더마다 |
| **액정 바탕 · 잉크 맨 톤** | `panel_u` · `ink_u` | 렌더마다 |
| **모서리 라운드(유무·반경)** | `corner_u` | 렌더마다 42% |
| **베젤 홈(유무·깊이)** | `groove` · `groove_u` | 렌더마다 40% |
| **글리프 폭 / 칸 피치** | `glyph_in_cell` | 렌더마다 |
| **잔상 농도** | `ghost` | 렌더마다 15% |
| **베젤 인쇄 문자열 · 변 · 자리** | `bezel_i` + 프로파일 `edge` | 렌더마다 |
| **시간·날짜 표기 포맷** | `time_fmt_i` | 렌더마다 |
| **도트줄 상단 문자열** | `dotrow_i` | 렌더마다 |
| **극성(mixed 해소)** | `polarity_u` | 렌더마다 |
| **화살표 종류 · 간격** | 프로파일 첫 종 · 갭 중앙값 | 렌더마다 |
| **요소 존재 여부** | 선언되면 항상 그린다 | 확률 게이트 |

`generic_v1` 에는 형질이 없다. 그게 이 풀의 존재 이유다 — 프로파일 밖 배치의
다양성 하한이라 여러 기기를 뭉뚱그린 익명 풀이다.

### B. 기기 상태 — 기기는 같아도 장마다 켜지고 꺼진다

`STATEFUL_ELEMENTS` = mem 표기 · 식전후(AC/PC) 마커 · 화살표(미터기 제외) ·
배터리 · 블루투스 · mem-flag · 혈액방울 · smile.

자리·크기·모양은 고정이고 **켜짐 여부만** 렌더가 정한다. 미터기 화살표는 여기
없다 — Instant 34장 전부에 있고 값에 묶인 지시자다.

### C. 촬영 변인 — 장마다 달라야 한다

크롭 종횡비 · 프레이밍(마진) · 회전 · 키스톤 · 노이즈 · 블러 · 명암 ·
비네팅 · 국소 그림자 · 반사 패치 · 대비 열화 계수 · 배경색 · 값 ·
시간/날짜의 내용.

## 곁가지로 잡은 것

**단위는 혈당 값과 같은 줄에 놓이지 않는다**(사람 규칙, raw Case 9). 근거
사진 9종을 전부 열어 확인했다 — 842(gmate) · 1058(onetouch_ultra) ·
1911(caresens_n_premier) · 228(gc_ms_one) · 475(acura_plus) · 267
(accuchek_instant) · 120(dorucos_premium) · 1186(performa_silver) ·
1781(green_doctor). **9/9 가 숫자 아래 오른쪽**이다. 같은 줄인 기기는 없었다.

프로파일 11종의 단위 자리를 `below-right` 로 통일하고, 같은 줄 자리를 선언하면
렌더가 assert 로 죽게 했다. 밴드 폭 역산이 단위 자리를 미리 떼던 몫(`_allow`)도
따라서 사라진다 — 숫자가 그만큼 넓어진다.

**아이콘 게이트가 뒤집혀 있었다.** `rng.random() > (0.0 if lay ... else p)` 는
기기 고정 기기에서 사실상 항상 참이라 아이콘을 늘 건너뛰었다. 항상 그리려던
의도의 정반대다. `_shown` 으로 대체했다.

## 남은 것

- **`avgrow` 가 120장 중 12장에서 배치 실패**로 빠진다(acura_plus). 선언된
  요소가 기기에서 상시 빠지면 '고정'이 아니다.
- **Instant 미터기 점 열이 유리 밖에 있다.** 근거 사진 267 은 점 열이 어두운
  창 '안'에 있다(색까지 있다 — 인쇄다). 코드는 몸체 마진에 그린다.
- **dorucos_premium `dot_panel=True` 가 의심스럽다.** 근거 사진 120 을 3배
  확대해 보니 큰 숫자가 꼭짓점이 뾰족한 7-세그먼트다. 도트 격자가 아니다.
  694·695 를 마저 봐야 판정할 수 있다.
- 가로형 기기가 프로파일에 하나도 없다 — 가로형은 `generic_v1` 에서만 난다.
