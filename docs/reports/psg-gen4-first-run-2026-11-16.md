  가시성 4회 재추출 루프. 잔여: 60그룹 중 2건은 재추출 전부 실패(극단
  줄아웃) — 사실상 단색 음성으로 거동, 학습 무해·층화 해석 미세 오차.

  3,998, 60에폭 — 30에폭판은 CTC 초기 국면 탈출 지연으로 80.5% 저수렴,
  60에폭에서 100% 수렴)·ps_rdr_neg(+빈타깃 396, 출하후보 검출기 크롭).

## 읽을 때

1. **합성 VAL 의 음성 축은 포화** — 완전 수렴 리더면 음성만으로 0 도달.
   거절 학습의 남은 시험대는 실데이터(238 재판·라이브)뿐이다.
2. **리더 빈타깃 = 안전 우선 트레이드오프**: 오답 확정 22-29 → 15-19 로
   줄이는 대신 미확정(확신도) 25-37 → 218-231. 확정 자동기록의 오답이
   사용자에게 더 위험한 축이라는 원칙에 부합하지만, 확정율 93%→70% 는
   실사용 체감 비용이다 — **출하 조합 선택은 사람 판정**(⑧ 판정 기준).
3. 검출기 음성 학습은 양성에 무해(738→744) — 재확정.
