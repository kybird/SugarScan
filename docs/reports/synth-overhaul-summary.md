## 이 체인이 남긴 것

- **폐기 전제 둘의 교체 근거**: (a) 2자리 밴드는 빈 칸을 포함한다
  (0.866 vs 3자리 0.891, n=32/185 — 구판 0.571 은 84장 편향 표본).
  (b) 가로형 사람 라벨 두 종류 — 칼럼형은 숫자필드만, 행형은 단위·시간까지.
- **유리 경계 하드 에지가 링 엣지의 ~25%** 였던 것 — 페더링으로 해소.
- **채움 루프의 결합**(몸체 감량 → 안쪽 필러 증가)은 안티패턴 문서 그대로
  작동했다. 필러 양자 축소로 허용폭 안에 들었으나 선택 루프(별도 카드)가
  풀리기 전까지 안쪽은 상한(1.51%) 가까이에서 운용된다.
- **극성 구조 문제의 수치화** — 어떤 자연스러운 구현도 33.7±5 에 못 들어간다
  (최소갱신 11.7% / 기기균등 39.3% / 기기충실 ~51%). 사람 결정 대기.
