# GM 검출 추론 전처리 A/B — 스트레치에서 레터박스로 (2026-09-16)

재학습 없음. 체크포인트는 `yolox_out/gmscreen_ft3/best_ckpt.pth` 하나로 고정하고
**추론 전처리만** 바꿔 잰다.

## 어긋남이 둘이었다

카드는 기하 하나(스트레치 vs 레터박스)를 지목했는데, 코드를 읽으니 채널 순서도
어긋나 있었다.

| 축 | 학습(YOLOX) | 기존 추론(`detect_datumo_gm.py`) |
|---|---|---|
| 기하 | 레터박스 — `r = min(비율)`, 남는 자리 114 회색 (`data_augment.py:142-155`) | `cv2.resize(img0,(imgsz,imgsz))` 스트레치 |
| 채널 | BGR — 로더가 `cv2.imread` (`datasets/coco.py:148`), preproc 는 채널을 안 바꾼다 | `img[..., ::-1]` 로 RGB |

파일 머리말에 적혀 있던 "YOLOX evaluator와 동일 전처리: 스트레치+BGR" 은 **두
군데 다 사실이 아니었다.** 두 축을 한 번에 바꾸면 어느 쪽이 움직였는지 알 수
없으므로 `--preproc` 로 갈라 세 팔로 잰다.

- `stretch` — 기존 경로 그대로(스트레치 + RGB). 기본값이라 동작이 안 바뀐다
- `letterbox` — 기하만 맞춤(레터박스 + RGB)
- `yolox` — 둘 다 맞춤(레터박스 + BGR). `ValTransform` 과 같은 그림

## 재현

```bash
cd assets_dev/train
python detect_datumo_gm.py --selftest          # yolox 모드 == YOLOX preproc 대조
for m in stretch letterbox yolox; do
  python detect_datumo_gm.py --preproc $m \
    --ckpt yolox_out/gmscreen_ft3/best_ckpt_np1.pth --imgsz 416 \
    --out _diag/preproc_ab/$m.jsonl
done
python gm_preproc_ab.py \
  --arm 운영=gmscreen_quads.jsonl \
  --arm letterbox=_diag/preproc_ab/letterbox.jsonl \
  --arm yolox=_diag/preproc_ab/yolox.jsonl --wide-detail
```

`*_np1.pth` 는 `migrate_ckpt_numpy1.py` 로 연 체크포인트다 — 원본은 numpy 2.x 로
절여져 지금 환경에서 `ModuleNotFoundError: No module named 'numpy._core'` 로
안 읽힌다. 가중치는 같다.

### 기준선을 먼저 맞췄다

`stretch` 팔이 운영 `gmscreen_quads.jsonl` 과 **좌표까지 동일**하다(앞 40장
전수 대조, 최대 좌표차 0.0). 즉 이 리팩터링은 기존 경로의 동작을 바꾸지 않았고,
아래 표의 `운영` 과 `stretch` 는 같은 줄이다. 운영 파일을 만든 체크포인트가
`ft3/best_ckpt` 라는 것도 이 대조로 확정했다(카드가 적어 둔
`gmscreen/latest_ckpt.pth` 는 2026-09-12 ft3 승격 이전의 기록이라 낡았다).

## 개수 지표가 이 개선을 거의 못 본다

`diag_wide_gm.py` 의 판정(미검출이거나 w/h < 1.2 면 실패)으로는:

| 팔 | OK | 미검출 | 접힘 | GM 실패 |
|---|---:|---:|---:|---:|
| 운영 | 31 | 7 | 11 | **18/49** |
| letterbox | 32 | 3 | 14 | **17/49** |
| yolox | 32 | 3 | 14 | **17/49** |

18 → 17. 개수만 보면 "거의 변화 없음"이다. 그런데 같은 장의 w/h 자체는 뚜렷이
움직인다:

| 팔 | n | p25 | p50 | p75 | w/h ≥ 1.2 |
|---|---:|---:|---:|---:|---:|
| 운영 | 42 | 1.21 | 1.98 | 2.15 | 31장 |
| letterbox | 46 | 1.12 | **2.30** | 2.51 | 32장 |

장 단위로 보면 접힘으로 남은 장들이 전부 문턱 쪽으로 올라왔다 — 0.72→1.17,
0.71→1.06, 0.80→1.10, 0.68→0.91, 0.92→1.15. **1.2 를 못 넘었을 뿐 다 좋아졌다.**
문턱 세기가 연속량의 이동을 통째로 삼킨 것이다. 개수와 분포를 나란히 놓지
않았으면 이 실험을 "효과 없음"으로 닫을 뻔했다.
