# 제2세대 순수합성 제품 계보 — 학습 설계 (2026-11-16)

사람 방향 결정(2026-11-16): **학습은 실사진 0%** — 원래 계획(SPEC §5.3)으로
복귀. Datacluster CC0 238장은 **측정(재판) 전용**이며 학습에 쓰지 않는다.
어젯밤 증명된 거절 학습("마지막까지 못 본 것"의 학습)을 계보에 처음부터
포함한다. 셀렉트스타·로보플로우 의존은 제거(라이선스 정본 §4 2026-11-16).

## 0. "해결"의 정의 (이 설계의 계약)

합성 지표는 방향 확인용일 뿐이다. 이 계보의 성패는 **목표 축**에서만 판정한다:

1. **Datacluster 238장 정지사진 채점** — 사람이 단 값 정답표로, 앱 확정
   규칙(검출 게이트→판독→값검증→확신도 0.85)을 그대로 재현한 파이프라인이
   낸 최종값과 비교. 정답 확정 / 오답 확정 / 미확정 / 비혈당계 거절을 센다.
2. **실기기 라이브 스캔** — 실혈당계를 카메라로 찍어 확정까지. C10 의
   라이브 축. (전제 블로커: 그 기기에서 라이브가 사용불가 화면으로 죽던
   문제를 먼저 잡는다.)

판정 기준(정답 확정 하한·오답 확정 상한)은 **결과를 보기 전에 사람이
정한다** — 채택 문서(모자이크 설계 §6)의 원칙을 그대로 계승.

## 1. 학습 데이터 — 전량 합성, 거절 포함

어젯밤 파이프라인(장면그룹 3변형)을 최종 생성기로 다시 굽는다. 규모 확대:

| 풀 | 그룹 수 | 이미지 | 시드 | 비고 |
|---|---|---|---|---|
| SGD2_TRAIN | 8000 | 24,000 (양성 8000·음성 16000) | 20261120 | plain_p 0.10 |
| SGD2_READER | 4000 | 12,000 | 20261121 | 리더 크롭 원천 |
| SGD2_VAL | 800 | 2,400 | 20261122 | 합성 방향 확인용 |

- 생성기는 클램프·재현 결정성이 확인된 현재 HEAD. 세 풀 모두 교차 동일
  픽셀 0 검증(`--verify`)을 통과해야 한다.
- **하드 네거티브 채굴(2단계, 선택)**: 초기 체크포인트가 높은 점수를 준
  합성 음성을 SGD2_TRAIN 안에서 재샘플링해 재학습(모자이크 설계 §3 계승).
  실사진 채굴은 하지 않는다 — 재판 오염.

## 2. 검출기 — 거절 학습 기본 탑재

- 구조/설정: BandNet width 1.5(현 배포와 동일)·grow 0.06·aug·steps 6000·
  batch 32·seed 고정. **--neg-ratio 0.25**(양성 32+음성 8 별도 부분)을
  기본 레시피로.
- 대조 arm(양성만) 1개를 함께 돌려 목표축 채점에서 거절 학습 기여를
  분리한다 — 어젯밤 행렬의 축소 재현, 비용 6분/arm.

## 3. 리더 — 빈 타깃 포함, 배포 검출기 크롭

- 크롭 원천: **거절 학습 검출기(출하 후보)**가 SGD2_READER 에서 제안한
  상자를 앱과 같은 방식(144×96)으로. 양성 크롭=값 라벨, 음성 크롭=길이 0
  CTC 타깃(비중 25%).
- reader_crnn 레시피: 어젯밤과 동일(aug·epochs 30·batch 32). 양성만 대조
  arm 1개.

## 4. 채점 — 3층

| 층 | 재료 | 역할 |
|---|---|---|
| 합성 SGD2_VAL | 기존 `eval_reject_stages.py` | 방향 확인(회귀 감시) |
| **Datacluster 238 재판** | 사람 값 라벨 + VOC 기기박스 | **목표 축 #1** — `eval_real_judge.py`(신규): 전 파이프라인 최종값 vs 정답표, 기기별 층화 |
| 실기기 라이브 | 사람 손의 혈당계 | **목표 축 #2** — 확정율·지연·실패 목록(C10 연계) |

- 238장 값 라벨링: webtool 라벨러에 값 입력 큐 등록, **사람이 수행**.
  라벨은 정답표일 뿐 학습에 안 쓴다.
- 재판 결과 보고서: 모든 칸에 n 명시. 채택 권고는 내지 않는다.

## 5. 번들 교체(판정 후)

채택되면 `export_deploy_onnx.py` 로 ONNX 변환→전량 파리티→번들 교체.
