## [2026-11-15 error] Case 1: 무정보 단색 프레임이 교차풀 픽셀 분리 검사를 어긴다

### 검색 단서
교차풀 동일픽셀, 단색 대조군, plain_p, 퇴화 붙임, VERIFY FAIL, std=0,
무정보 프레임, 픽셀 해시 분리, 장면그룹 세트

### Grounding
- Git Context: `hash:c50adcc`
- Evidence: `build_synth_coco --verify` 출력 및 교차풀 md5 대조(본문)
- Confidence: 5/5

### 상황
- 장면그룹 세트 3풀(SGD_TRAIN/SGD_READER/SGD_VAL, 시드 상이) 굽기 뒤
  `build_synth_coco --verify`에서 `SGD_TRAIN∩SGD_VAL 동일 픽셀 1장`,
  `SGD_READER∩SGD_VAL 1장` FAIL. md5 대조로 범인 특정 — 충돌 4장 전부
  `std=0.0, unique=1`(완전 단색 프레임).
- Evidence: 교차풀 md5 대조 — 충돌 4장 전부 std=0.0, unique=1

### 가설
단색 프레임은 시드가 달라도 같은 픽셀이 될 수 있다 — 두 출처가 있다:
①단색 대조군(family=None) ②선언한 계열의 패치가 프레임 밖으로 완전히
나간 퇴화 붙임. 픽셀 해시 분리 검사는 '장면 누수'를 잡는 자인데 장면
정보가 0인 프레임은 우연한 충돌의 성격이 다르다.

### 판정
실측으로 확인(충돌 전부 std=0). 원칙: **검증 세트의 모든 프레임은 시드의
결정적 함수여야 분리 불변식이 성립한다.** 무정보 프레임은 그 전제를 깬다.

### 조치
방해물 붙임 클램프(패치 최소 40% 는 프레임 안 — 선언한 계열은 반드시
그린다) + `--plain-p` 인자(검증 세트는 0, 단색 대조군은 학습 풀에만).
재굽기 뒤 VERIFY PASS(3풀 동일픽셀 0).

## [2026-11-15 error] Case 2: 샘플러가 셔플 풀 '위치'를 아이템 인덱스로 오용 — n=6+14

### 검색 단서
배치 샘플러, 셔플 풀 위치, 아이템 인덱스 혼동, n=6+14, 스모크 우연 통과,
배치 구성 단언, NegRatioBatchSampler, c3994e8

### Grounding
- Git Context: `hash:c3994e8`
- Evidence: 샘플러 직접 순회 배치 구성 출력(n=6+14 → 16+4)
- Confidence: 5/5

### 상황
- `NegRatioBatchSampler.__iter__` 가 `[(bi*bs+k) % len(pos)]` 를 그대로
  yield — 셔플된 풀 리스트를 통과하지 않아 임의 아이템을 집었다.
- 스모크 세트(양성 12·음성 24, batch 16)에서 `n=6+14` 로 드러남. 더 작은
  스모크(n=4+1)는 우연히 올바른 구성을 내 눈을 속였다.

### 가설
'풀의 위치'와 '아이템 인덱스'는 셔플 뒤 다른 이름공간이다 — 매핑
`pos[...]` 없이 위치를 쓰면 임의 아이템을 집는다.

### 판정
샘플러 직접 순회로 배치 구성을 세어 확인(6양성+14음성). 매핑 수정 후
16+4. 원칙: **배치 구성 단언은 스모크에서도 매번 kind별 카운트로 직접
세라** — 통과한 스모크가 검증이 아니라 미검출일 수 있다.

### 조치
`idx = [pos[(bi*bs+k) % len(pos)] for k in ...]`(커밋 c3994e8). 샘플러에
args.seed 반영, 두 arm 이 같은 배치 경로를 쓰도록 통일(커밋 c50adcc).

- **Anti-Patterns**: [[unnamed-coordinate-frame]] (인덱스 공간의 무명 혼동)

## [2026-11-15 design] Case 3: 꺼짐 변형은 '완성본 지우기'가 아니라 '그리기 전 건너뛰기'여야 한다

### 검색 단서
꺼짐 변형, off_lcd, skip_digits, 제거 흔적, 음성 지문, 영분산 채움,
렌더 재현, 변형은 생성 매개변수, 적대적 리뷰, c50adcc

### Grounding
- Git Context: `hash:c50adcc`
- Evidence: 적대적 리뷰 보고서(std 0.00 실측)·수정 후 재측정(std ≥1.57)
- Confidence: 5/5

### 상황
거절 학습의 꺼짐(숫자 없음) 음성 변형을 처음엔 완성 양성에서 글리프
마스크로 지워 만들었다. 적대적 리뷰 서브에이전트가 실측으로 지적: 지운
영역이 std 정확히 0.00(주변 유리 8~47) — 광학 노이즈가 없는 실촬 불가능
영역, 즉 음성에만 생기는 합성 지문. 반사·그림자 이음매(경계 단차>12,
15/40장)도 남는다.

### 가설
변형은 파생(지우기)이 아니라 **생성 매개변수**여야 한다 — 설계 §1 표 3행
원문("숫자를 그리기 전에 글리프 렌더를 건너뛰고")이 정확히 이것을 못박았다.

### 판정
드로우 함수(`_draw_digit_uniform`·`_draw_ghost`)는 rng 를 소비하지 않는다
— 같은 시드 재렌더에서 숫자만 빼면 난수 흐름이 보존되어 몸체·보조 표기·
반사·그림자가 정상 변형과 동일해진다. 수정 후: 지움 영역 std ≥1.57(자연
유리 질감), 변경 국소 ≤3.8%(숫자 영역만). Confidence: 5/5

### 조치
`render_panel(skip_digits=)` + 장면그룹 굽기에서 같은 시드 이중 렌더.
`_erase_digits` 삭제(커밋 c50adcc). 대안이었던 '지운 뒤 노이즈 합성'도
기각 — 노이즈 모델 자체가 음성에만 존재하는 지문이 된다. Trade-offs:
그룹당 렌더 2배 비용 ↔ 변형 간 물리 일관성(실측 0.2s/그룹이라 저렸다).
Reversibility: High.
